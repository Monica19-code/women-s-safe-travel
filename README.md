🚺 Women Safe Travel Web Application

A **Women Safe Travel** web application designed to enhance personal safety during travel by providing real-time location sharing, emergency alerts, and quick access to trusted contacts. This project focuses on simplicity, usability, and safety-first design, especially for women traveling alone.

---

## 📌 Project Overview

The Women Safe Travel application helps users:

* Share live location with trusted contacts
* Send emergency alerts instantly
* Access safety features quickly through a clean dashboard
* Improve confidence and safety during daily travel

This project is suitable for **academic projects, hackathons, and portfolio demonstrations**.

---

## 🎯 Key Features

* 🔐 **User Authentication** (Login Page)
* 📊 **Dashboard** with quick navigation
* 🚨 **Emergency Alert Button**
* 📍 **Live Location Sharing** using browser GPS
* 👥 **Trusted Contacts** (predefined)
* 📱 **Mobile-friendly Responsive Design**

---

## 🚀 How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in any modern web browser (Chrome recommended)
4. Allow location permission when prompted

> ⚠️ Note: Location features require **GPS permission**.
